# تراث — إدارة الدراسات والبحوث التراثية الإماراتية

**TURATH — Emirati Heritage Studies & Research Department**

مؤسسة بحثية رقمية متخصصة في التاريخ الاجتماعي والثقافي والأنثروبولوجي والحضاري لدولة الإمارات، في صلاتها بالخليج العربي وشبه الجزيرة العربية والمحيط الهندي. وهي ليست مولّد نصوص وصفية عن التراث، بل منظومة عاملة للبحث والتحقيق والجمع الميداني والتوثيق والتحليل والنشر. تبني أرشيفاً معرفياً مستداماً يحفظ الأدلة الأولية ويربط كل استنتاج علمي بأصله.

```
الفكرة ← الفجوة ← الخطة ← الدراسات ← المصادر ← الأخلاقيات ← الجمع ← التفريغ ← النقد والتثليث
       ← التحليل ← الكتابة ← التحكيم ← التدقيق الحقوقي ← الإخراج ← الاعتماد البشري ← النشر والأرشفة
```

## التنصيب على جهاز واحد بأيقونة على سطح المكتب

انظر **[INSTALL.md](INSTALL.md)**. التنصيب سطر واحد يُلصق في PowerShell على ويندوز أو في Terminal على ماك. ينزّل البرنامج، ويثبّت Python إن لزم، ويضع أيقونة «تراث» على سطح المكتب، ويفتح اللوحة.

**دليل مصوَّر:** [`docs/guide/turath-guide.pptx`](docs/guide/turath-guide.pptx) — عرض من ثلاثين شريحة يشرح المنصة وشاشاتها وطريقة استخدامها. [تنزيل مباشر](https://github.com/7r425ypz9t-hue/turathres/raw/refs/heads/claude/clever-carson-78yimu/docs/guide/turath-guide.pptx)

## التشغيل في دقيقة (للمطورين)

يحتاج التشغيل إلى Python 3.10 أو أحدث، ولا يحتاج إلى أي مكتبة خارجية. أما مكتبة `python-docx` فاختيارية، ولا تلزم إلا لتصدير Word.

```bash
python -m turath setup solo      # أو lan أو team
python -m turath serve           # تفتح لوحة التحكم في المتصفح
python -m turath pilot           # استيراد النموذج التطبيقي «التلي» بمصادره المتحقق منها
python -m unittest discover -s tests
```

ويمكن التشغيل بالنقر المزدوج على المشغّل المناسب للنظام، وهو ينشئ أيقونة على سطح المكتب:
- ويندوز: `launchers\turath_windows.bat`
- ماك: `launchers/turath_mac.command`
- لينكس: `launchers/turath_linux.sh`

## أنماط التشغيل الثلاثة (اعتمادية ذاتية)

| النمط | لمن | كيف يعمل |
|---|---|---|
| `solo` | مستخدم واحد على حاسوب واحد | يستمع الخادم على `127.0.0.1` وحده، ويتولد رمز دخول جديد عند كل تشغيل، وتُرفض أي ترويسة Host غير محلية. |
| `lan` | مستخدم واحد على أجهزة متعددة من خادم محلي | الخادم على حاسوب في البيت أو المكتب تصله الأجهزة عبر الشبكة المحلية، والدخول بكلمة مرور (PBKDF2)، وTLS اختياري: `--cert --key`. |
| `team` | عدة مستخدمين | حساب لكل باحث. البحوث خاصة لا يطلع عليها الآخرون، والمشاركة صريحة: مصدر بعينه لمستخدم بعينه، أو دعوة شريك إلى مشروع بصفة «مؤلف مشارك» أو «مطّلع». والسجل الموسوم «خاص» يبقى لمالكه ولو كان داخل مشروع مشترك. |

البيانات كلها في مجلد واحد هو `~/Turath`، ويمكن تغييره بالمتغير `TURATH_HOME`. ويضم المجلد:
- قاعدة SQLite؛
- الخزنة، وفيها الأصول للقراءة فقط ومسار كل أصل مشتق من بصمته؛
- النسخ الاحتياطية، وكل نسخة ملف zip فيه بيان بالبصمات على نمط BagIt.

| التثليث المنهجي: ستة أصناف للأدلة، وفحص استقلال الشهادات، وسجل التعارضات | مُنفَّذ ومختبَر | `turath/evidence.py` |

| التصدير: Word بالهوية البصرية، وCSV، وJSON، وGeoJSON مع حجب المواقع الحساسة، وتنسيق APA 7 وChicago | مُنفَّذ | `turath/export.py` |

| البحث الدلالي بالمتجهات، وربط Google Drive وZotero | مواصفة قابلة للتنفيذ | `docs/12-integrations.md` |

## لوحة التحكم

| القسم | ما فيه |
|---|---|
| الرئيسية | مشهد الساحل عند الغروب، ومؤشرات حلقية، ومسار المراحل الست عشرة، والمجالات الستة، والنطاقات الجغرافية الثقافية الستة |
| المشاريع | البوابات والفحوص، وقرارات المراجعة، وسجلات المشروع، والشركاء |
| السجلات | نماذج مولَّدة من المخطط لكل كيان، مع سجل التغييرات والمشاركة |
| الخزنة | إيداع بالسحب والإفلات، ومعرض للصور، وفحص السلامة، والنسخ الاحتياطي |
| المختبر الشفهي | مشغّل الصوت، والخطوات الاثنتا عشرة، ومحرر التفريغ الحرفي والمقروء |
| الأدلة والتثليث | بطاقة الادعاء بأصناف الأدلة الستة، وهرم المصادر، وسجل التعارضات |
| الوكلاء والمهارات | الهيكل التنظيمي، والبطاقات الكاملة، وتكليف الوكلاء وسجل التكليفات |
| لوحة القيادة | المؤشرات الاثنا عشر، وخط الأساس |
| الوثائق | كل الوثائق والاستمارات معروضة وقابلة للطباعة |
| الإعدادات | الأنماط والمحركات والحسابات |

**ملاحظة على الصور:** صور الواجهة من مجموعة صاحب الإدارة (`turath/static/img/photos/`)، وهي للزينة لا دليلاً تاريخياً. والمولَّد منها موسوم «إعادة بناء تصورية» حيثما ظهر، ومصدر كل صورة ونوعها معروضان في الإعدادات (`credits.json`). أما الصور التي يودعها الباحث في الخزنة فتدخل «المسار الوثائقي» بعد توثيق مصدرها وحقوقها.

## النموذج التطبيقي التجريبي

[`pilot/README.md`](pilot/README.md) دراسة وثائقية عن «التلي»، مبنية على 12 مصدراً فُتحت وتُحقّق منها في 2026-10-14، و20 ادعاءً مربوطاً بأدلته، و7 تعارضات، و26 مفردة معلّقة على التحقق الميداني. صحّح التحقق افتراض الإدراج على قائمة الصون العاجل: العنصر مدرج على **القائمة التمثيلية** لليونسكو منذ 2022. والجمع الميداني مصمَّم ولم يُنفَّذ.

## المبادئ غير القابلة للتفاوض

1. **صفر تلفيق.** لا يُختلق مرجع ولا راوٍ ولا مقابلة ولا صفحة ولا DOI. وهذا مفروض في الدستور وفي البوابات وفي المؤشرات.
2. **الأرشيف هو المرجع، لا ذاكرة النموذج.** كل إجابة تُتتبَّع إلى نص أو صورة أو تسجيل أصلي.
3. **اللفظ المحلي كما نُطق.** لا تفصيح في التفريغ الحرفي، ولا تخمين لما لم يُفهم.
4. **السيادة البشرية.** لا يُنشر شيء قبل اعتماد المراجع البشري المخوّل.
5. **الواقعية.** يُفصل بين ما صُمِّم وما نُفِّذ، ولكل أداة حالتها الفعلية.
